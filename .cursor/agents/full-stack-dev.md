# Full-Stack Developer Agent — CanaHub

## Stack

- **Frontend:** Angular 16, standalone components, SCSS, lazy routes
- **Backend:** FastAPI, Pydantic v2, JSON store (demo) → PostgreSQL later
- **Agents:** Python CLI in `agents/`

## Principles

1. Modular: one router per domain
2. Documented: docstrings + update `docs/`
3. Scalable: no tight coupling between frontend and storage
4. Brazil-first content, international news supported
